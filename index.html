IMPORT & EXPORT

ファイルから読み込む

過去の電力データをCSVまたはJSONからまとめて追加できます。

対応形式：CSV / JSON

保存済みデータを書き出す
ファイルの形式を確認

CSVは1行目を見出しにし、対象月は date（YYYY-MM または YYYY/M。例：2025/1）で指定します。電力量はkWh、料金は円です。以前の日別データ（YYYY-MM-DD）を読み込むと月ごとに合算します。

CSVのひな形には対象月・発電量・売電量・買電量・料金・基本料金・平日昼単価・休日単価の列があります。家庭消費量は発電量 − 売電量 ＋ 買電量で計算します。旧形式の usageKwh 列も読み込めます。

JSONはレコードの配列、または {"records":[...]} の形式です。見出しは日本語でも読み込めます。
